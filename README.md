One-star alien review of Earth that still compliments the food — entry for
[make.fun](https://make.fun/bounty/u-po-pu-one-star-five-stars-for-the-food-f9166ee7).

## The line

> One star: your gravity shattered my luggage, your queues defy physics, but the noodle soup was so good I nearly forgave your entire solar system.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

The program guards the gate itself: one sentence, 1–200 characters, verified
by a round-trip read-back before it exits.
